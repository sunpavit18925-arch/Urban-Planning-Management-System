# ระบบการติดตามงานวางและจัดทำผังเมือง (UPMS)

UPMS ใช้ค้นหาผังเมือง ดูสถานภาพรายพื้นที่ และติดตามขั้นตอนการดำเนินงาน เลือกเวอร์ชันเพื่อดูซอร์สโค้ดและวิธีรันบนเครื่อง

[![เปิดคู่มือ PHP](https://img.shields.io/badge/PHP-777BB4?style=for-the-badge)](./php/README.md) [![เปิดคู่มือ TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge)](./project-typescript-react-express-nodejs-api/README.md)

| เวอร์ชัน | การทำงาน | ข้อมูลตัวอย่าง |
| --- | --- | --- |
| [PHP](./php/) | PHP สร้างหน้าเว็บและรายงาน ใช้ jQuery โหลดข้อมูลเมื่อเลือกเมนู | SQLite เก็บข้อมูลที่แก้ไขไว้บนเครื่อง |
| [TypeScript](./project-typescript-react-express-nodejs-api/) | React, Express และ SQLite พร้อมนำเข้า Excel/CSV ส่งออก Excel แนบเอกสาร และประวัติการแก้ไข | SQLite เก็บข้อมูลและไฟล์แนบไว้หลังรีสตาร์ต |

ทั้งสองเวอร์ชันรันแยกกันได้ และแต่ละเวอร์ชันมีชุดข้อมูลของตัวเอง

เวอร์ชัน TypeScript มี 48 เมนู ครอบคลุมทะเบียนผัง ขั้นตอนย่อย งาน ม.35/ประเมิน หมายเหตุ รายงานและแผนที่ บริษัท/โครงการ/อุปกรณ์ แผนบำรุงรักษา นำเข้า–ส่งออก ไฟล์แนบ ประวัติ และบัญชีพร้อมตรวจสิทธิ์ มีเช็กลิสต์เทียบไฟล์ PHP 210 ไฟล์กับส่วนที่พัฒนาใหม่ พร้อมการทดสอบ API/กฎธุรกิจ/เบราว์เซอร์ อ่าน[วิธีรันและขอบเขตการย้ายระบบ](./project-typescript-react-express-nodejs-api/README.md) โดยยังเก็บเวอร์ชัน PHP สำหรับอ้างอิงต้นฉบับ

เวอร์ชัน PHP เผยแพร่ 152 ไฟล์ที่มีเส้นทางเรียกจากหน้าเริ่มต้น ตัวสร้างข้อมูล และรายงานที่ระบุในคู่มือ รวมถึงเป้าหมายของเมนูที่ปิดอยู่แต่ยังมีฟังก์ชัน JavaScript เรียกได้ ส่วน 58 ไฟล์ที่ไม่พบเส้นทางเรียก เช่น backup หน้าทดลอง และข้อมูลแผนที่ซ้ำ ถูกนำออกจาก Git โดยยังเก็บสำเนาบนเครื่องเดิมและกู้ได้จากประวัติ ดู[รายการไฟล์และเหตุผล](./php/docs/runtime-files.json) และ[ขอบเขตการตรวจ](./php/README.md)

สถิติ Languages บน GitHub วัดจากขนาดซอร์สโค้ด ไม่ใช่จำนวนฟีเจอร์หรือความสมบูรณ์ของแต่ละเวอร์ชัน `.gitattributes` ไม่นับชุดข้อมูลแผนที่ ไลบรารีภายนอก asset และโมดูลอ้างอิงที่สร้างจากเครื่องมือ รวมถึงไฟล์ PHP ซ้ำที่ระบุไว้ โดยยังนับซอร์ส PHP กับ TypeScript ตามภาษาของไฟล์ GitHub จะคำนวณสถิติใหม่หลัง push ไปยังสาขาหลัก
