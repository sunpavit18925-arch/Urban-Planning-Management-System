# การตรวจไฟล์ขนาดใหญ่

ตรวจจากซอร์สหลัง commit `1865cb6` โดยเก็บ PHP 152 ไฟล์ที่มีเส้นทางเรียกตาม [runtime-files.json](./runtime-files.json) การตรวจซ้ำไม่พบ PHP ที่ไม่มีเส้นทางเรียกเพิ่มเติม ส่วน PHP ที่นำออกก่อนหน้านี้ 58 ไฟล์ยังมีหลักฐานสำหรับกู้คืนในรายการเดียวกัน

| กลุ่มไฟล์ | ขนาดใน Git ก่อนตัดไฟล์รอบนี้ | การจัดการ |
| --- | ---: | --- |
| `php/tree_chart2/` | 8.44 MB | นำไฟล์ต้นแบบ 53 ไฟล์ออกจาก Git; ไม่มีหน้า PHP/HTML เหลือและไม่พบตัวเรียกจากโปรเจกต์ เก็บสำเนาบนเครื่อง |
| `php/js/province.js` | 1.64 MB | นำข้อมูลซ้ำออกจาก Git; เนื้อหาเหมือน `provinces.js` ที่หน้าแรกเรียกใช้ เก็บสำเนาบนเครื่อง |
| `php/img/` | 23.70 MB | เก็บภาพที่มีอยู่; รูปภาพไม่ใช่ซอร์สภาษาสำหรับ Languages |
| `php/pdf/` | 7.90 MB | เก็บคู่มือ; PDF ไม่รวมใน Languages |
| `php/bower_components/` | 3.71 MB | เก็บไลบรารีที่หน้าเว็บใช้; ระบุ `linguist-vendored` แล้ว |
| `php/dist/` | 3.36 MB | เก็บชุดธีมและ asset; ระบุ `linguist-vendored` แล้ว |
| `php/tree_chart/` | 8.43 MB | เก็บหน้าตัวอย่าง HTML; ระบุเฉพาะ Bootstrap, Font Awesome และ Owl Carousel เป็นไลบรารี ไม่ครอบ CSS ที่เขียนเอง |
| `client/public/php/` ในโปรเจกต์ TypeScript | ส่วนหนึ่งของ public assets | เก็บรูป CSS ฟอนต์ Chart.js และคู่มือที่ TypeScript ใช้; ระบุ `linguist-vendored` แล้ว |

ไลบรารี Bootstrap และ Font Awesome ถูกกฎมาตรฐานของ GitHub Linguist แยกอยู่แล้ว การเพิ่มกฎเฉพาะใน `.gitattributes` ทำให้ตรวจสอบเจตนาได้ชัดเจน จึงไม่ควรคาดว่าเปอร์เซ็นต์ PHP จะลดลงอีกจากกฎเหล่านี้ การเอาข้อมูลซ้ำที่ไม่นับอยู่แล้วออกช่วยลดไฟล์ในสาขาปัจจุบัน แต่ไม่ลบไฟล์ในประวัติ Git

PHP ที่เหลือมีโค้ด HTML, CSS และ JavaScript อยู่ใน template ด้วย GitHub นับขนาดทั้งไฟล์ตามภาษา PHP จึงยังมีสัดส่วนสูง แม้ไม่นับไลบรารีภายนอกแล้ว ไม่มีการกำหนดให้ละเว้นทั้งโฟลเดอร์ PHP หรือไฟล์ธุรกิจที่ยังถูกเรียก

หลักฐานไฟล์ที่นำออกเพิ่มเติม: [unused-assets.json](./unused-assets.json) การตรวจเส้นทางใน repo ไม่ครอบคลุมลิงก์หรือ bookmark ที่เก็บอยู่ภายนอก
