# UPMS เวอร์ชัน PHP

[กลับหน้าเลือกเวอร์ชัน](../README.md) · [เปิดคู่มือ TypeScript](../project-typescript-react-express-nodejs-api/README.md)

ระบบติดตามผังเมืองฉบับ PHP ใช้ jQuery และ AdminLTE สำหรับเมนู แผนที่ และรายงาน ตัวอย่างนี้เปิดด้วยบัญชีผู้ดูแลจำลองอัตโนมัติ เหมาะสำหรับทดลองบนเครื่องส่วนตัว

## เปิดใช้งาน

ต้องมี PHP พร้อมส่วนขยาย PDO SQLite และสิทธิ์เขียนไฟล์ในโฟลเดอร์ `php/` เริ่มจากโฟลเดอร์หลักของ repo

```sh
cd php
php -S 127.0.0.1:8080
```

เปิด [หน้าสร้างข้อมูลตัวอย่าง](http://127.0.0.1:8080/mock_db_setup.php) แล้วกด **เข้าสู่ระบบหลัก** หรือเปิด [หน้าแรก UPMS](http://127.0.0.1:8080/) ระบบจะสร้าง `mock_db.sqlite` ในโฟลเดอร์นี้ และเก็บการแก้ไขไว้หลังปิดเซิร์ฟเวอร์ กด `Ctrl+C` เพื่อหยุด

ถ้าใช้ XAMPP บน Windows และเรียก `php` จาก PowerShell ไม่ได้ ให้ใช้ `C:\xampp\php\php.exe -S 127.0.0.1:8080` จากโฟลเดอร์เดียวกัน

## เริ่มอ่านโค้ด

- [index.php](./index.php) และ [nav1.php](./nav1.php) เปิดหน้าแรกและโหลดเนื้อหาตามเมนู
- [app/show_extra.php](./app/show_extra.php) แสดงผังตามขอบเขตการปกครอง ส่วน [report/tree-chart.php](./report/tree-chart.php) แสดงภาพรวมในรูปแผนผังต้นไม้
- [mock_db_setup.php](./mock_db_setup.php) สร้างตารางและข้อมูลตัวอย่าง ส่วน [js/function_db.php](./js/function_db.php) อ่านและเขียนข้อมูลผ่าน PDO

สำเนาสาธิตใช้รหัสผู้ใช้และเบอร์ติดต่อจำลอง และปิดการส่งข้อความไปยัง LINE

## ไฟล์ที่เผยแพร่และไฟล์เก่า

จาก PHP เดิม 210 ไฟล์ เก็บไว้ใน Git 152 ไฟล์ และนำออก 58 ไฟล์ รวมประมาณ 2.39 MB เพราะไม่พบเส้นทางเรียกจาก `index.php`, `mock_db_setup.php` และรายงาน `report/tree-chart.php` ที่เปิดแยกได้ การตรวจตาม include/require, AJAX และไฟล์ JavaScript ที่อ้างถึงต่อกัน โดยเก็บเป้าหมายของ dispatcher แม้เมนูจะถูกปิดไว้ รวมทั้ง URL รายงานที่ประกอบจากตัวแปรไว้ก่อน

[รายการตรวจ](./docs/runtime-files.json) บันทึกไฟล์ที่เก็บพร้อมผู้เรียก และไฟล์ที่นำออกพร้อมเหตุผล SHA-256 และ Git blob ไฟล์ที่นำออกเป็นสำเนาเฉพาะเครื่องเดิมและถูกระบุใน `.gitignore` ผู้ clone ใหม่จะไม่ได้รับไฟล์เหล่านี้ แต่กู้ต้นฉบับจาก commit `a3aa5603a3b1e8c153b21a9acf819427742874ee` ได้ เช่น:

```sh
git show a3aa5603a3b1e8c153b21a9acf819427742874ee:php/report/pro_result-backup.php
```

ขอบเขตนี้เป็นการตรวจเส้นทางใน repo และทดสอบหน้าสาธิต ไม่ครอบคลุมผู้ที่บันทึก URL ของไฟล์เก่าไว้ภายนอก หรือรับรองว่าทุกหน้าที่เมนูเดิมปิดไว้ทำงานสมบูรณ์

ตรวจซ้ำจากโฟลเดอร์ TypeScript ด้วย `npm run audit:php` และ `npm run test:php` คำสั่งทดสอบต้องมี PHP/PDO SQLite และ Chrome/Edge โดย lint PHP ทั้ง 152 ไฟล์ แล้วเปิดเบราว์เซอร์กับสำเนาเฉพาะไฟล์ที่เผยแพร่และฐานข้อมูลใหม่ ตรวจหน้าแรก ภาค เขตตรวจราชการ การเจาะพื้นที่/ย้อนกลับ รายงานต้นไม้ และหน้าต่างรายละเอียดผัง สำเนาไฟล์เก่าบนเครื่องจึงไม่สามารถซ่อน dependency ที่ขาดได้

การทดสอบเก็บคำเตือน PHP ใน log (`display_errors=0`) และรายงานปัญหาเดิมของหน้า demo แยกไว้ ได้แก่กราฟตัวอย่าง AdminLTE ที่ไม่มี container กับ favicon 404 โดยยังตรวจให้ไม่มีข้อผิดพลาดใหม่จากไฟล์ที่นำออก
